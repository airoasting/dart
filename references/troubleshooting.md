# 문제가 생기면

SKILL.md의 각 단계가 멈출 때 연다. 원칙은 하나다: **고칠 것은 조각 파일(parts)에서 고치고 `assemble_report.py build` → `verify_report.py` → `build_report.py` 순서로 다시 돈다.** data.json이나 HTML을 직접 고치면 다음 조립에서 사라지거나 게이트가 빌드를 막는다(잠정실적 경로만 예외).

## 시작 전

| 증상 | 원인 | 해결 |
|---|---|---|
| "DART_API_KEY가 없습니다" | 키 미설정 | `~/.claude/skills/dart/.env`에 `DART_API_KEY=발급받은_키` 한 줄. 키는 opendart.fss.or.kr에서 무료 |
| 종목을 못 찾음 (신규 상장·사명 변경) | 목록이 오래됨 | `corp_registry.py --refresh` 뒤 다시 찾는다 |
| status 020 | DART 일일 한도(2만 건) 초과. `DartClient`가 이미 두 번 더 시도한 결과 | 내일 다시 하거나 다른 키 |
| status 800 | DART 점검 | 잠시 뒤 다시 |

## facts · build 단계

| 증상 | 원인 | 해결 |
|---|---|---|
| facts: "핵심 계정이 없다" | 매출·영업이익·순이익 중 하나가 DART에 없음(일부 금융업 등) | 게이트를 통과할 수 없다. 사용자에게 알리고 중단 |
| facts: "재무제표를 받지 못했다" | 그 분기 정기보고서 미제출 | `period`로 직전 분기로 만들거나, 사용자가 원하면 `references/provisional.md` |
| facts: "개별재무제표(OFS)로 만든다" | 연결재무제표 없음 | 정상. build도 자동으로 같게 처리한다 |
| facts: "DART에 접속하지 못했다" / "일일 호출 한도" | 네트워크 / status 020 | 잠시 뒤 다시 / 내일 다시 또는 다른 키 |
| build: "SEGS 합계가 총매출과 다르다" | A2의 부문 숫자 | 메인이 A2.json에 차이만큼 `연결조정` 행(`est: true`)을 넣는다. 부문 숫자를 새로 찾아야 하면 같은 템플릿으로 A2를 새로 띄운다 |
| build: "PERSONAS가 13인이 아니다" | B 출력 | 같은 템플릿으로 B를 새로 띄운다(빠진 인물만 메인이 쓰지 않는다. 판단 규칙 적용이 B의 일이다) |
| build: "증권사 목표가가 없다" | A2에 tp 없는 항목 | 메인이 그 항목을 A2.json에서 뺀다. 남는 곳이 없으면 A2를 새로 띄운다 |
| build: "meta 키가 다르다" | data.example.json 계약이 바뀜 | 조립 스크립트와 예시를 맞춘다(스킬 유지보수 사항) |
| 조각 파일 JSON이 깨짐 | 에이전트가 설명문을 섞음 | 같은 템플릿에 오류 내용을 덧붙여 그 에이전트를 새로 띄운다(SKILL.md Step 4의 재시도 규칙) |
| 게이트 "지배주주순이익과 일치" 힌트 | 순이익 기준이 다름 | 지배주주 기준이 의도라면 facts·build에 `--np-basis parent`를 붙여 다시 조립 |

## 숫자 검증 게이트

| 증상 | 원인 | 해결 |
|---|---|---|
| A층 산술 불일치 | 조각 숫자 오타, 부문 합계 | 해당 조각을 고치고 다시 조립 |
| B층 "식별" 불일치 | 다른 회사의 corp_code·종목코드 | Step 1을 다시 돌려 corp_code를 확인하고 처음부터 |
| B층 전년동기 불일치 | (조립 스크립트를 쓰면 생기지 않는다) 손으로 작년 보고서 숫자를 씀 | 이번 보고서의 재작성치. 조립 스크립트를 쓴다 |
| C층 "데이터에서 나오지 않는 숫자" | B·C 문장에 facts에 없는 숫자, 또는 파생 숫자(차이·비율) | B.json·C.json에서 숫자를 빼거나 facts 표기로 바꾸고 다시 조립. 기사 숫자를 꼭 써야 하면 원문을 확인해 `V1.json`의 `claims`에 `{text, url, status}` |
| V2가 DART 공시 부문 숫자를 `unverified`로 | dart.fss.or.kr 뷰어는 WebFetch에 목차만 보인다 | V2 템플릿대로 `dart_text.py <rcpNo> "영업부문"`으로 본문 표를 읽게 한다(단위 천원·백만원을 억원으로 바꿔 비교) |
| C층 출처 기록 없음 | V1·V2가 없거나 `unverified` | 검증 에이전트를 다시 돌리거나, 확인 못 한 항목을 조각에서 뺀다(부문은 `est: true`) |
| INCOMPLETE (코드 3) | 네트워크 | 회차를 쓰지 않았다. 한 번 더, 또 실패하면 사용자에게 |
| BLOCKED (코드 2) | 3회차 소진 | SKILL.md Step 6의 세 가지 선택지를 사용자에게 묻는다 |
